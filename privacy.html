Privacy & data handling

Version 4.1.0 · Last updated September 13, 2026

This independent extension has one purpose: user-initiated OAuth credential export as JSON for Cockpit.

Data handled

Access tokens, refresh tokens, ID tokens, email, account identifiers and expiry metadata returned by OAuth. Passwords are entered on the provider website, not in this extension. It does not scan webpages, read chat content, cookies or existing ChatGPT sessions.

Use and transmission

After your acknowledgement and sign-in click, OpenAI receives an OAuth request. The extension sends the returned authorization code and PKCE verifier to the HTTPS token endpoint on auth.openai.com. The provider sees normal network information such as your IP address. Provider login pages and redirects are governed by provider policies.

Credentials are not sent to a developer-operated server. The extension has no analytics, advertising, tracking or remote executable code. It does not automatically connect to Cockpit. When you confirm Copy JSON, credentials are written to your system clipboard; you choose where to paste them.

Storage and retention

Credentials remain in this Chrome profile's local extension storage until you select Clear credentials or uninstall. They are not stored using Chrome sync. Storage is not an encrypted vault. Temporary OAuth state is held in session storage and expires after ten minutes; cancellation removes it. Chrome may delay cleanup while the browser is suspended; expired callbacks are rejected.

Your controls

You can decline sign-in, cancel a pending login, decline an export or clear saved credentials. Clear also removes credentials retained from the previous version, including legacy Claude data. Claude login and export are no longer supported; legacy data is retained only until you choose Clear. Clear cannot erase clipboard history, OS/cloud clipboard sync, backups, downloaded files or imported copies. Clearing does not revoke tokens at the provider. Use provider account controls if revocation is needed.

Limited use

Data is used only for the stated credential export feature. It is not sold, used for advertising, used to assess creditworthiness or lent to others. The extension's use of user data adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

Security warning

Anyone with exported credentials may be able to access your account. Only paste into an installation you trust. Never post JSON publicly or send it to support. Other applications and clipboard history/sync may retain it.
